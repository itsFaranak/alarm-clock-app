# Alarm Clock (Python + PyQt5)

A simple and functional **Alarm Clock application** built with **Python** and **PyQt5**.  
It features a clean graphical user interface that allows users to **set, stop, and snooze alarms** easily.

---

## Features
- Displays the current **time** and **date**
- Set custom **alarm times**
- Add a **custom alarm message**
- **Snooze** function (adds 5 minutes)
- **Stop alarm** button
- Plays a **sound alert** when the alarm goes off
